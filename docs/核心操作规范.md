### 2. 核心操作流程

#### 2.1 任务发布流程
1. **用户操作**：首页/列表页 → 点击"发布任务" → 发布任务页
2. **数据提交**：填写任务信息 → 调用 `publishTask` 云函数
3. **结果处理**：发布成功 → 跳转到我发布的任务页
4. **数据更新**：更新发布任务计数，刷新任务列表

#### 2.2 任务参与流程
1. **用户操作**：任务详情页 → 点击"加入任务" → 确认页面
2. **数据提交**：确认加入 → 调用 `joinTask` 云函数
3. **结果处理**：加入成功 → 返回任务详情页
4. **数据更新**：更新参与任务计数，刷新任务状态

#### 2.3 任务管理流程
1. **发布者管理**：
   - 编辑任务：调用 `updateTask` 云函数
   - 删除任务：调用 `deleteMyTask` 云函数
   - 开始任务：调用 `startTask` 云函数
   - 结束任务：调用 `endTask` 云函数
2. **参与者管理**：
   - 退出任务：调用 `deleteMyTask` 云函数
   - 标记完成：调用 `markTaskFinished` 云函数
   - 评价任务：调用 `rateTask` 云函数

### 3. 云函数功能详解

#### 3.1 任务管理云函数
- **publishTask**：发布新任务，创建任务记录和发布者参与记录

- **deleteMyTask**：删除任务或退出任务，支持积分返还
- **joinTask**：加入任务，创建参与记录，支持重新加入
- **startTask**：开始任务，扣除积分，更新参与者状态
- **endTask**：结束任务，发放奖励，更新任务状态
- **markTaskFinished**：参与者标记个人任务完成
- **removeTaskJoiner**：发布者移除参与者
- **remindTaskParticipants**：提醒参与者

#### 3.2 任务查询云函数
- **getAllTasks**：获取所有任务列表，支持分页和筛选
- **getMyPublishedTasks**：获取用户发布的任务，支持分类统计
- **getMyJoinedTasks**：获取用户参与的任务，支持分类统计
- **getTaskDetail**：获取任务详细信息
- **getTaskProgress**：获取任务进度和参与者状态
- **getMyFavTasks**：获取用户收藏的任务
- **category-tasks**：按分类获取任务

#### 3.3 任务互动云函数
- **likeTask**：点赞/取消点赞任务
- **rateTask**：评价任务，更新评分和评论
- **addTaskComment**：添加任务评论
- **getTaskComments**：获取任务评论列表
- **getMoreReplies**：获取更多回复

#### 3.4 状态管理云函数
- **updateJoinStatus**：更新参与状态（就绪/取消就绪）
- **publishAndJoinedCounts**：获取发布和参与任务数量

# 发布的任务/参与的任务 页面核心操作规范 
# 页面路径：pages\ucenter\myTasks\joined.vue  pages\ucenter\myTasks\published.vue

## 1. 页面：我参与的任务（joined.vue） & 我发布的任务（published.vue）

### 1.1 数据加载与刷新
- 支持下拉刷新（onPullDownRefresh）：重置页码，强制拉取第一页数据，更新缓存快照。
- 支持触底加载（onReachBottom）：页码+1，拉取下一页数据，追加到列表。
- 首次加载/切换筛选条件时，优先命中缓存快照（1分钟有效，按筛选条件和分类分组）。
- 缓存快照结构：{ ts, data: { tasks, hasMore, pagination } }，每个筛选条件/分类独立缓存。

### 1.2 左滑操作（uni-swipe-action）
- 支持操作：
  - 编辑（仅发布者/未开始，跳转 publish.vue，调用 updateTask 云函数）
  - 删除/退出：
    - 未开始、已失效、已评价：
      - 仅参与：显示"退出"按钮
      - 发布并参与/发布者：显示"删除"按钮
    - 其他状态（如已完成未评价、进行中）：不显示删除/退出按钮
  - 评价（已完成，未评价，右滑弹出评价抽屉，调用 rateTask 云函数）
  - 查看评价（已评价，右滑弹出只读评价抽屉）

### 1.3 操作逻辑与云函数
- **数据获取**：
  - getMyPublishedTasks（published.vue）
  - getMyJoinedTasks（joined.vue）
- **编辑任务**：
  - 跳转 publish.vue，带 id 和 edit=1 参数
  - 调用 updateTask 云函数，更新 kl-tasks 表
- **删除/退出任务**：
  - 调用 deleteMyTask 云函数，见本规范前述详细逻辑
  - 影响 kl-tasks（主表）和 kl-users-join-task（关系表）
- **评价任务**：
  - 右滑"评价"按钮，弹出评价抽屉，填写评分和内容，调用 rateTask 云函数，更新 kl-users-join-task 表
- **查看评价**：
  - 右滑"查看评价"按钮，弹出只读评价抽屉，展示评分、内容、时间

### 1.4 页面跳转
- 编辑：跳转 publish.vue
- 评价/查看评价：弹出抽屉，无页面跳转
- 详情：点击卡片跳转 detail.vue

### 1.5 影响的数据表
- kl-tasks：任务主表（编辑、删除、参与人数变更等）
- kl-users-join-task：任务参与关系表（退出、评价、软删除等）

### 任务删除/退出核心操作规范
### 1.6 发布者删除
- **未开始**：主表软删除并参与人数清零，所有参与关系软删除且状态设为 removed。
- **已完成/已失效**：主表软删除，所有参与关系软删除且状态设为 removed。
- **进行中**：禁止删除，返回错误提示。

### 1.7 参与者退出
- **未开始**：主表参与人数减1，自己参与关系软删除且状态设为 quit。
- **已完成/已失效**：自己参与关系软删除且状态设为 deleted。
- **进行中**：禁止删除，返回错误提示。

### 1.8 任务计数更新规范
#### 1.8.1 计数字段
- `store.userInfo.publishedCount`：用户发布的任务数量（未软删除）
- `store.userInfo.joinedCount`：用户参与的任务数量（未软删除）

#### 1.8.2 更新时机
- **页面进入**：`ucenter.vue` 的 `onShow` 生命周期调用 `publishAndJoinedCounts` 云函数
- **发布任务**：`publishTask` 云函数成功后返回 `publishedCount`，前端更新 `store.userInfo.publishedCount`
- **加入任务**：`joinTask` 云函数成功后返回 `joinedCount`，前端更新 `store.userInfo.joinedCount`
- **删除/退出任务**：`deleteMyTask` 云函数成功后返回 `publishedCount` 和 `joinedCount`，前端同时更新两个计数
- **开始任务**：`startTask` 云函数成功后返回 `score`，前端更新 `store.userInfo.score`

#### 1.8.3 云函数返回格式
```javascript
// 成功时返回格式
{
  code: 0,
  message: '操作成功',
  publishedCount: 5,  // 发布任务数量
  joinedCount: 3,     // 参与任务数量
  score: 100          // 积分余额（开始任务时返回）
}
```

#### 1.8.4 前端更新逻辑
```javascript
// 在相关操作成功后更新计数
// 错误方式：直接赋值（不会持久化）
// store.userInfo.publishedCount = res.result.publishedCount;

// 正确方式：使用 mutations.setUserInfo 方法（会持久化到本地存储）
if (res.result.publishedCount !== undefined) {
  mutations.setUserInfo({ publishedCount: res.result.publishedCount });
}
if (res.result.joinedCount !== undefined) {
  mutations.setUserInfo({ joinedCount: res.result.joinedCount });
}
```

**重要提醒**：所有涉及 `store.userInfo` 数据更新的地方都必须使用 `mutations.setUserInfo()` 方法，而不是直接赋值。这样可以确保数据持久化到本地存储，避免页面重新加载时数据丢失。

#### 1.8.5 角标显示
- 在 `ucenter.vue` 的网格项中使用官方 `uni-badge` 组件
- 使用 `absolute="rightTop"` 定位到右上角
- 使用 `type="error"` 红色样式，`size="small"` 小尺寸
- 当计数为 0 时角标会自动隐藏
- 组件会自动处理数字显示和样式

### 1.9 发布者兼参与者的特殊处理
#### 1.9.1 按钮显示逻辑
- **发布者兼参与者**：只显示"确认完成"或"查看进度"按钮，默认自己的任务已完成
- **仅参与者**：显示"标记完成"按钮
- **仅发布者**：显示"结束任务"或"查看进度"按钮

#### 1.9.2 完成状态检查
- 检查所有参与者完成状态时，排除发布者自己
- 如果只有发布者自己参与，直接认为可以结束任务
- 发布者结束任务时，不给自己发放奖励积分

#### 1.9.3 积分更新
- 结束任务成功后，返回发布者的最新积分余额
- 前端使用 `mutations.setUserInfo({ score: newScore })` 更新积分

   - 调用 `handleTaskStatusChange(task._id, task.status, 'in_progress')`
   - 触发 `refreshCurrentCategory()` 刷新数据

**云函数流程（startTask/index.js）**：
1. **权限验证**：检查操作者是否为发布者
2. **获取参与关系**：查询所有 `isActive: true` 的参与记录
3. **过滤参与者**：排除发布者，只计算其他参与者
4. **检查就绪状态**：确保有参与者状态为 `ready`
5. **时间检查**：确保在开始前30分钟内
6. **积分计算**：计算需要扣除的积分（参与者数量 × 每人积分）
7. **积分检查**：验证发布者积分是否足够
8. **扣除积分**：记录积分支出到 `uni-id-scores` 表
9. **更新参与者状态**：
   - 将所有 `ready` 状态的参与者改为 `in_progress`
   - 如果发布者也是参与者，将其从 `preJoin` 改为 `in_progress`
10. **更新主表**：任务状态改为 `in_progress`，更新 `joined_count`
11. **返回结果**：包含扣除后的新积分值

**数据刷新流程**：
1. **`handleTaskStatusChange`** → 调用 `refreshCurrentCategory()`
2. **`refreshCurrentCategory`** → 重置页码，清空任务列表
3. **`fetchMyPublishedTasks({ reset: true })`** → 强制重新获取数据
4. **缓存更新**：新数据会更新缓存
5. **UI更新**：`this.$forceUpdate()` 强制更新界面

- 只有发布者兼参与者才能看到"开始"按钮

- 状态变更后任务会从"待开始"分类移动到"进行中"分类

- 分类切换时优先使用缓存，提高性能
- 缓存失效时自动重新获取数据

**积分处理**：
- 云函数返回扣除后的新积分值
- 前端立即更新 `store.userInfo.score`
- 确保积分显示的一致性

**状态流转**：
- 任务状态：`not_started` → `in_progress`
- 参与者状态：`ready` → `in_progress`
- 发布者状态（如果参与）：`preJoin` → `in_progress`
- 分类变化：从"待开始"移动到"进行中"

**错误处理**：

**方法实现**：
```javascript
// 发送提醒
async sendReminder(member) {
  try {
    const res = await uniCloud.callFunction({
      name: 'sendTaskReminder',
      data: { 
        taskId: this.progressData.task._id, 
        joinerId: member._id,
        userId: this.userId 
      }
    });
    
    if (res.result && res.result.code === 0) {
      uni.showToast({ title: '提醒发送成功', icon: 'success' });
    }
  } catch (error) {
    uni.showToast({ title: '提醒发送失败', icon: 'none' });
  }
}

// 移除参与者
async removeJoiner(member) {
  uni.showModal({
    title: '踢除参与者',
    content: `确定要踢除参与者"${member.nickname}"吗？`,
    confirmText: '确定踢除',
    confirmColor: '#ff4757',
    success: async (res) => {
      if (res.confirm) {
        const res = await uniCloud.callFunction({
          name: 'removeTaskJoiner',
          data: { 
            taskId: this.progressData.task._id, 
            joinerId: member._id,
            userId: this.userId 
          }
        });
        
        if (res.result && res.result.code === 0) {
          uni.showToast({ title: '踢除成功', icon: 'success' });
          this.refreshProgress();
        }
      }
    }
  });
}
```
